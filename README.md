# Food Tracker

แอป Flutter สำหรับบันทึกมื้ออาหารในแต่ละวัน โดยเก็บชื่ออาหาร มื้ออาหาร ตัวเลขปริมาณ จำนวนคน วันที่ และรูปอาหารได้

## ฟีเจอร์

- ดูรายการของวันที่เลือก พร้อมค้นหาชื่ออาหารและกรองตามมื้อ
- เพิ่ม แก้ไข และลบรายการอาหาร
- เลือกรูปจากคลังภาพหรือถ่ายรูปใหม่
- ดูสรุปจำนวนรายการแยกตามมื้อ
- เริ่มต้นด้วยรายการว่าง แล้วให้ผู้ใช้เพิ่มข้อมูลเอง

## เริ่มใช้งาน

ต้องติดตั้ง Flutter SDK ก่อน จากนั้นรันในโฟลเดอร์โปรเจกต์:

```powershell
flutter pub get
flutter run
```

สร้าง Web build และเปิดพรีวิวในเครื่อง:

```powershell
flutter build web
node tools/preview_server.cjs
```

จากนั้นเปิด http://localhost:8080

## การจัดเก็บข้อมูล

ถ้าไม่ได้ตั้งค่า Supabase แอปเก็บรายการใน SharedPreferences ของอุปกรณ์หรือเบราว์เซอร์ รูปที่เลือกจะถูกเก็บร่วมกับข้อมูลในโหมดนี้ การล้างข้อมูลเบราว์เซอร์อาจลบรายการในโหมดเว็บ

มีไฟล์ SQL และ repository สำหรับ Supabase ในโปรเจกต์ แต่การเปิดใช้การซิงก์ออนไลน์ต้องตั้งค่า credentials และเชื่อม flow เข้าสู่ระบบก่อน ห้ามใส่ Supabase service-role key ในแอป

## โครงสร้างหลัก

- `lib/screens/` หน้าต้อนรับ รายการอาหาร ฟอร์ม และสรุป
- `lib/models/` โมเดลรายการอาหาร
- `lib/services/` การจัดเก็บข้อมูลและการเชื่อมต่อ
- `lib/widgets/` ส่วนประกอบ UI ที่ใช้ซ้ำ
- `supabase/schema.sql` โครงสร้างฐานข้อมูลและ Storage policies
